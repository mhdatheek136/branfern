# Paper Hoof — Color Palette Reference

This file serves as the official color reference for the Paper Hoof brand identity. All design systems, UI components, and marketing materials should refer to these hexadecimal values to ensure visual consistency.

---

## Primary Brand Colors

| Color Name | Hex Code | Purpose & Usage |
| :--- | :--- | :--- |
| **Horse Black** | `#202423` | Primary text, navigation elements, icons, and dark-themed surfaces. |
| **Sheep White** | `#FFFDF7` | Primary background canvas, card surfaces, and generous whitespace zones. |

---

## Secondary & Accent Colors

| Color Name | Hex Code | Purpose & Usage |
| :--- | :--- | :--- |
| **Mane Orange** | `#E34C18` | **Action.** Active indicators, CTA (Call to Action) buttons, and critical highlights. |
| **Saddle Green** | `#01360A` | **Legacy.** Secondary emphasis, directional icons, and high-end graphic accents. |
| **Truck Grey** | `#83A1AC` | **Utility.** Muted surfaces, UI panels, image placeholders, and subtle borders. |
| **Barn Beige** | `#FFF093` | **Warmth.** Limited highlight areas, text background accents, or soft dividers. |

---

## Usage Guidelines

1. **Hierarchy:** Maintain a ratio of roughly 70% Sheep White, 20% Horse Black, and 10% Accents.
2. **Accessibility:** Ensure Horse Black text on Sheep White background maintains a high contrast ratio for readability.
3. **Restraint:** Mane Orange and Saddle Green should be used sparingly to guide the user's eye without creating visual noise.
